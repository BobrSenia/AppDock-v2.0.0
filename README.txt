AppDock Update 3 — обновлённый интерфейс и поведение

В архиве:
- MainWindow.xaml
- MainWindow.xaml.cs
- AppData.cs
- dionishuesos.csproj

Установка:
1. Закройте AppDock и Visual Studio.
2. Сделайте копию папки проекта или хотя бы четырёх файлов, которые заменяете.
3. Скопируйте файлы из архива в корень проекта dionishuesos.
4. Согласитесь на замену.
5. Откройте проект в Visual Studio.
6. Выберите Сборка -> Пересобрать dionishuesos.
7. Если ошибок нет, нажмите F5.

Старые пользовательские данные НЕ удалять:
%APPDATA%\AppDock\appdata.json
%APPDATA%\AppDock\Icons
%APPDATA%\AppDock\Shortcuts

Что изменено:
- Положение окна сохраняется при закрытии и сворачивании в трей.
- Приложения открываются одним кликом.
- Сетка динамически увеличивается, прокрутка появляется только при необходимости.
- После удаления элементов сетка уплотняется.
- Прозрачность фона: 0 = полностью прозрачно, 1 = полностью непрозрачно. Иконки не становятся прозрачными.
- Фоновая картинка назначается как Background кисть закруглённой Border, поэтому углы остаются скруглёнными.
- Название папки показывается по центру верхней панели и обновляется при вводе.
- Настройки закрываются стрелкой или кликом вне панели.
- Добавлен выбор произвольного цвета через стандартный Windows Color Dialog (в нём есть поле выбора оттенка/насыщенности и яркости).
- Ползунок прозрачности получает точку значения при клике по дорожке.
- Полоса прокрутки тонкая, скруглённая и тематически окрашивается.
- Перетаскивание сбрасывает старые анимации перед следующим движением.
- Потеря фокуса (в том числе Alt+Tab) прячет AppDock в системный трей.
- Двойной клик по значку AppDock в трее восстанавливает окно; контекстное меню трея содержит «Открыть AppDock» и «Выход».
- Кнопка X и пункт «Закрыть» закрывают программу полностью.

Примечания:
- Проект использует WPF и Windows Forms для NotifyIcon/ColorDialog; оба флага уже включены в csproj.
- Сборка в этой среде не запускалась, так как .NET SDK здесь отсутствует. XAML и csproj проверены как корректный XML; компиляцию необходимо проверить в Visual Studio.
