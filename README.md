# AppDock

A customizable desktop app launcher for Windows.

AppDock is a lightweight floating launcher that helps you organize and quickly access your applications, files, and shortcuts.

## Features

- Customizable appearance, themes, colors, and transparency
- Drag and drop applications, files, and folders
- Organize shortcuts in a compact grid
- Custom application icons
- Background image support
- Minimize to system tray
- Persistent settings and window position
- Single-click application launching

## Installation

1. Download the latest release from the [Releases](../../releases) page.
2. Extract the ZIP archive.
3. Run `dionishuesos.exe`.

The published build is self-contained and targets Windows x64.

## Requirements

- Windows 10 or Windows 11 (64-bit)

## Building from source

1. Install the .NET 10 SDK.
2. Open `dionishuesos.csproj` in Visual Studio.
3. Build or publish the project.
